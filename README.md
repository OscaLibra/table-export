# 页面表格导出 Excel（table-export）

浏览器扩展：识别当前页面**已渲染**的表格，按用户所选列导出为 Excel。

> 对应《浏览器页面表格导出Excel插件——可行性与开发方案》文档实现，当前版本覆盖 **P1 MVP + P2 语义网格** 范围。

## 核心承诺（合规边界）

- **只读**：对页面仅做读取（文本、属性、计算样式、控件当前值），不点击、不滚动、不派发事件、不改 DOM；
- **被动**：一切动作由用户在弹窗中显式触发，无任何后台自动行为；
- **最小权限**：仅声明 `activeTab` + `scripting`，安装零提示，无任何主机权限；
- **所见即所得**：导出内容严格等于页面当前已渲染内容。分页/懒加载/虚拟滚动场景**只导出当前已渲染的行**，并以数字明确告知（如"仅导出当前页 50 行"），绝不模拟翻页补数据。用户自己手动翻页/滚动后再次导出完全合规。

## 功能

- 表格检测：原生 `<table>` + ARIA 语义网格（`role=table/grid`，覆盖 Ant Design、Element 等主流组件库）；穿透 open Shadow DOM；支持 iframe（allFrames 注入）
- 列选择：默认全选，隐藏列置灰不可选，支持全选/清空；预览前 10 行
- 合并单元格：表头横向合并展平为"父列名-子列名"，数据纵向合并值下穿填充
- 类型推断（保守策略）：千分位/货币符号数字 → 数值单元格；前导零编号（0012）、超 15 位长数字（证件号/卡号）、混合串 → 强制文本；日期不转换
- Excel 版式：表头加粗、冻结首行、列宽自适应；文件名"页面标题_表格名_时间戳.xlsx"
- 截断提示：ARIA `aria-rowcount` 虚拟滚动检测、常见分页容器识别；>5 万行需确认，>20 万行拒绝
- 零构建、零网络：运行时不发起任何外部请求，依赖全部随包捆绑（内网可用）

## 安装（内网环境）

### 方式一：开发者模式加载（小范围试点）

1. 解压 `table-export-v0.1.0.zip`（校验 SHA-256 摘要见 `dist/*.sha256`）；
2. 打开浏览器扩展管理页：Chrome `chrome://extensions` / Edge `edge://extensions`；
3. 打开右上角（Edge 为左侧）"开发者模式"；
4. 点"加载已解压的扩展程序"，选择解压出的 `table-export` 目录；
5. 固定到工具栏，在目标页面点击图标即可使用。

### 方式二：企业策略预装（规模化推广）

通过 Chrome/Edge 组策略 `ExtensionInstallForcelist` 下发内部签发的 crx 包，实现静默安装与版本统一管控（详见方案文档 5.6 节）。策略键示例：

```
HKLM\SOFTWARE\Policies\Google\Chrome\ExtensionInstallForcelist
  1 = "<extension_id>;file:///<内部共享路径>/table-export.crx"
```

版本升级：替换共享路径中的新版本包，用户重启浏览器后生效；每次发布随附 SHA-256 摘要供分发前核验。

## 使用

1. 打开含表格的页面，点击扩展图标；
2. 多表时下拉选择目标表格（显示行列数、隐藏列、分页/截断提示）；
3. 勾选需要导出的列（可先点"预览"看前 10 行）；
4. 点"导出 Excel"，完成后浏览器自动下载。

## 支持范围与限制

| 场景 | 行为 |
| --- | --- |
| 静态表格 | 全部行导出 |
| 分页表格 | 仅当前页，明示行数并引导手动翻页 |
| 懒加载长列表 | 已加载部分，明示行数 |
| 虚拟滚动（带 aria-rowcount） | 明示"已渲染 N 行 / 共 M 行" |
| 虚拟滚动（无标注） | 通用提示，不强行猜测 |
| canvas 绘制表格 | 不支持，明确提示 |
| closed Shadow DOM | 无法访问（浏览器安全限制） |

## 开发与测试

```bash
# 合规静态扫描（构建期保障：注入源文件禁止模拟操作/网络请求）
node tools/scan.js

# 单元/冒烟测试（需 jsdom，NODE_PATH 指向依赖目录）
NODE_PATH=<node_modules> node tests/smoke.test.js      # 检测+提取逻辑 24 项
NODE_PATH=<node_modules> node tests/exporter.test.js   # 类型推断+Excel生成 28 项

# 手测：浏览器加载扩展后打开 tests/sample-page.html 覆盖 7 类场景

# 打包（zip + SHA-256，输出 dist/）
python tools/pack.py
```

## 工程结构

```text
table-export/
├── manifest.json            # MV3：activeTab + scripting，无主机权限
├── src/
│   ├── popup/               # 弹窗 UI（主控、样式、导出模块）
│   ├── core/                # 注入函数源：detect/extract，零依赖纯函数
│   └── lib/                 # 供应商化 ExcelJS 4.4.0（版本锁定）
├── icons/                   # 16/48/128 图标
├── tests/                   # 冒烟测试 + 样例页（7 类场景）
├── tools/                   # 合规扫描、打包、图标生成
└── dist/                    # 发布产物（zip + sha256）
```
